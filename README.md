Este proyecto fue desarrollado como parte de mi práctica en ingeniería de software aplicada al análisis de datos.

# El objetivo principal es fortalecer habilidades técnicas clave como:

Creación y gestión de entornos virtuales en Python
Organización estructurada de proyectos
Desarrollo de aplicaciones web
Buenas prácticas de documentación
Control de versiones con Git y GitHub
Aunque se utiliza un conjunto de datos de anuncios de venta de vehículos, el enfoque principal no es el análisis exploratorio, sino la correcta configuración del entorno de desarrollo y la implementación de una aplicación web funcional.

# Para este proyecto se creó un entorno virtual llamado:
vehicles_env
Este nombre está directamente relacionado con el dataset utilizado.

# 🛠️ Tecnologías Utilizadas

Python 3.x
venv (Virtual Environments)
Pandas
Framework Web (Flask / Streamlit)
Git & GitHub

# ⚙️ Configuración del Entorno Virtual
1️⃣ Crear el entorno virtual
python -m venv vehicles_env
2️⃣ Activar el entorno virtual
Windows:
vehicles_env\Scripts\activate
Mac/Linux:
source vehicles_env/bin/activate
3️⃣ Instalar dependencias
pip install -r requirements.txt
▶️ Ejecutar la Aplicación
python app.py

# o si se usa Streamlit:
streamlit run app.py
